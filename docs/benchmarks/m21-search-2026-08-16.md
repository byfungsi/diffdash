# M21 Fixed-Space Search Evidence, 2026-08-16

## Scope

FUN-236 establishes the fixed-space search algorithm and deterministic integration evidence needed
by D-10. It does not claim packaged repository-scale latency, RSS, swap, or throughput results. Those
measurements remain to be run against the generated M21 fixtures in a packaged application.

## Implemented Decision

- Search scans transactionally visible committed snapshot blocks through the generation-scoped Core
  snapshot repository. It does not build or persist a row, object, or cursor offset for every match.
- Provisional updates report monotonic lower-bound totals after bounded blocks. They intentionally
  expose neither final directional cursors nor wrap completion.
- A complete scan reports the exact total and one bounded page. Directional navigation rescans from
  semantic file, hunk, line, and UTF-16 substring coordinates while retaining at most one requested
  page (or one bounded previous-page ring).
- File anchors rotate snapshot order without copying the inventory or the match set.
- Search examines only context, addition, and deletion content after the canonical patch marker.
  Hunk headers and metadata lines are excluded. Literal occurrences are case-sensitive and
  non-overlapping; substring coordinates use JavaScript UTF-16 offsets expected by DOM ranges.
- Every returned excerpt has its own UTF-8 byte cap. Cropping expands around the match without
  splitting a Unicode code point.
- Each scan owns a generated snapshot repository session. Interruption closes that session, and a
  replacement scan supersedes blocked work before it can continue to another committed block.
- A separate utility worker was not added. Reads are already bounded and interruptible at the
  repository boundary, while the scan retains only a bounded page and one current-hunk state.

## Deterministic Evidence

`packages/core/src/services/snapshot-search.test.ts` uses real `node:sqlite` metadata and managed
filesystem blocks to cover:

- 1,000 nearly-every-line matches with a retained page of three results and monotonic lower bounds;
- exact totals, anchor rotation, semantic next/previous cursors, and bounded directional rescans;
- content-only scope, case-sensitive exact literals, non-overlap, Unicode content, and UTF-16 offsets;
- independently byte-capped excerpts that preserve complete Unicode code points;
- query supersession, explicit interruption, and repository session release.

The focused suite passed locally on 2026-08-16. Test duration is not capacity evidence and is not used
to select production limits.

## Remaining Measurement And Integration

Run the packaged broad-search and enormous-file fixtures and record fixture ID, DiffDash commit,
machine profile, peak Core and worker RSS, swap, first provisional latency, final latency, directional
rescan latency, cancellation latency, and managed-disk deltas before promoting D-10 to a packaged
scale decision.

The Core RPC and renderer still use the legacy parsed-snapshot search contract. A later cutover must
encode progressive versus final states, semantic directional cursors, capped excerpts, and explicit
cancellation without restoring complete parsed-diff or complete match retention.
